# 长期历史研究（P2）

入口：定投计划 → 计划设置 → 长期历史研究。「获取历史并比较」按当前目标权重、交易费用及独立的月度研究预算读取行情，不改变实际定投频率、持仓、策略或交易记录。

本阶段提供价格基准的滚动历史研究。它不执行参数搜索，不是工作区完整策略回测，也没有完成样本外验证，更不能据此声称年化 10%+ 可实现。

## 数据与状态

`POST /api/strategy/research` 接受：

```json
{
  "target_weights": {"510300": 60, "518880": 40},
  "monthly_budget": 2000,
  "trading_cost": {"lot_size": 100, "min_commission": 5, "commission_rate_pct": 0.03, "max_fee_ratio_pct": 0.25},
  "investment_goal": {"annual_return_target_pct": 10, "horizon_years": 10}
}
```

代码须为六位数字，最多 12 只，正权重合计须为 100%。预算须大于零。参数错误返回 HTTP 400 `invalid_request`，不会先请求行情。`trading_cost` 可省略而使用默认值，显式的 0 费用保留。

默认调用现有行情服务的 `range=max`，Yahoo 请求全历史，备用源最多请求 5,200 条日线。腾讯拒绝过长区间且返回空数据时，回退到已有五年请求格式；**供应商仍可能只返回更短的数据，月份数以实际记录为准**，不把请求区间当成真实覆盖。

也可显式传 `price_history: {代码: [{date, close}]}`，此时完全不访问行情源。用于复现和受控数据测试，不会把调用方数据标成真实供应商数据。

- 排除当前未结束月份及未来日期，截止日为上月最后一天。
- 使用所有目标 ETF 的共同交易日，每月选最后一个共同交易日，不用前值填充、不跳过目标品种、不拼接代理指数。
- 无效价格记录被丢弃并计数；同日冲突价格停止比较。月份不连续，或月末距离最后共同报价超过十个自然日，也停止比较。
- 取最近至多 181 个共同月度观测。基础研究至少需要 37 个，相当于 36 个持有期；这不是长期策略已获验证的门槛。
- 覆盖不足返回 HTTP 422 `insufficient_history`，逐只列出来源、实际起止、月份数及错误，`strategies` 为空，不返回伪零收益。
- 基础历史足够返回 HTTP 200 `ready`，但十年或个人期限的窗口仍可单独为 `insufficient_history`。

当前来源可能使用原始或前复权收盘价，**含分红总回报口径尚未核验**。复权、分红再投资、税费、汇率、滑点和历史执行质量需要进一步验证。页面明确采用“价格基准研究”名称。

## 三个固定基准

| ID | 基准 | 行为 |
| --- | --- | --- |
| `fixed` | 定额 | 每月入金后按目标权重分配可用现金 |
| `cashflow` | 现金流补缺 | 每月按投入后的金额缺口分配，只买不卖 |
| `rebalance` | 年度再平衡 | 每年一月先卖出超配部分，再按缺口买入 |

每个完整区间及每个滚动窗口均从空仓开始、每月投入相同金额，余款结转到后续月份。三者共用整手、佣金及手续费占比限制。现金流补缺研究会使用结转现金，**不等同于实际工作区保留现金池的完整执行策略**。卖出费用高于成交额或超过费用比例限制时不执行该笔模拟卖出。

计量沿用 [PORTFOLIO_BACKTEST.md](PORTFOLIO_BACKTEST.md)：扣交易费后的时间加权收益、ACT/365 年化、XIRR、月度最大回撤、本金、净盈亏、费用与现金占比。月度最大回撤可能遗漏月内深跌。

## 滚动窗口

预设 36 / 60 / 120 个月持有期，分别需要 37 / 61 / 121 个观测。每次向后移动一个月；若个人投资期限不同，再加入向上取整到月的目标期限窗口。

每组返回所有窗口的日期与指标、窗口数量、年化收益最小值／中位数／最大值，以及达到已保存年化目标的历史窗口占比。未填写收益目标时，达标占比为 `null`。重叠窗口不是独立样本，历史占比不是未来概率。

`methodology.out_of_sample` 和 `methodology.future_target_validated` 始终为 `false`。`goal_horizon_status` 为 `historical_only` 仅说明能计算该期限的历史窗口，不能解释为收益验证通过。

## 页面状态与复现

请求可取消或在三分钟后超时。取消停止浏览器等待，已在服务器开始的只读计算可能继续完成。结果仅保留在当前页面内存，刷新页面后清空。

请求捕获当时的目标权重、目标、费用和研究预算。等待期间或结果返回后改变这些参数，页面将结果标成旧配置，不会把旧响应解释为新参数的结论。行情刷新、持仓份额变化不使空仓基准研究失效。

「导出研究 JSON」包含原始请求参数、结果与对齐后的价格观测。成功研究可用导出的 `request` 再调用相同接口复算；这不会再次请求历史行情。源覆盖明细和逐窗口结果也留在导出文件中。它不是工作区备份。

## 验证与后续

测试覆盖入金与净收益分离、费用、37 / 61 / 121 个观测边界、短历史 ETF、日期冲突、月份缺口、未来日期、长区间降级、来源错误、导出复算，以及配置改变后的旧结果判定。页面用独立临时工作区验证桌面和 375px 手机布局。

后续要验证长期收益目标，仍需：可信的含分红历史或明确标注的指数研究数据、日频风险路径、按当时可获得信息重放完整执行规则，以及预先固定参数后的样本外评估。本阶段没有以月度价格研究替代这些工作。
