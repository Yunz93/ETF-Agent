# 组合使用说明

## 首次启用

1. 在“资产与持仓”核对类别目标，合计100%。已有A500、恒生科技等资产会保留在额外类别中，默认目标为0%。
2. 核对场内/场外产品代码与类型；同类可以包含多只ETF或联接基金。更换产品身份会清除原行情；有交易后请新增产品，不直接改成另一基金。
3. 按真实账户补充期初现金与持仓。期初是建账日余额，建账日前交易仅存档。
4. 点击“备份并启用组合”。迁移前文件会自动备份，可在设置中恢复。

## 日常记账

- 入金/出金只改变现金，不算投资收益。
- 场内成交录入实际份额、价格和费用。
- 场外申请先录入金额或赎回份额，状态选择“申请待确认”；收到确认单后录入实际份额、净值与费用。申请资金不与基金份额重复计算。
- 红利再投填入新增份额、净值和费用；现金分红填写金额及费用。
- 资料错误使用“更正”并填写原因；实际账外增减持仓使用“持仓校正”。校正会暂停该范围的期间收益计算。

## 行情和收益

场内可以刷新报价；场外净值在产品详情录入或批量导入，每行“日期,净值”，必须填写来源。已有历史可补录，最新估值取最新日期。缺行情时不猜价格；历史估值只沿用过去7个自然日内的已知行情。

类别占比以基金投资市值为分母，现金单列。组合收益含账户现金，单产品/类别收益只包含对应持仓及其买卖、分红流，不包含其他账户资金。期初现金未知会影响组合收益，但不影响资料完整的单产品收益。

## 投资计划

建仓预算与周期定投预算分别设置。类别可指定主要产品，或给产品填写类内分配权重；填写权重后按权重相对比例分配。没有可买产品、行情不足、现金不足或不能满足交易单位时，资金保留为现金。未明确启用替代时不会擅自换产品；设置类内固定权重的产品不自动互相替代。

逢低计划按可用历史最近120条记录的高点检查回撤，至少需要20条记录。计划分配是当前条件预览；“本期处理完毕”只推进日期，不能代替实际成交记账。

## 模拟的解释范围

模拟从历史空仓开始，使用所选配置的相同比例，不把今天的份额倒填到历史。两策略同日同额入金，闲置现金参与收益和回撤计算。回撤分档信号取前一共同日期，下一共同日期按收盘价/净值近似成交；不模拟真实确认延迟、历史申购限制、溢价、滑点、税费和赎回费用。现场逢低计划是条件预览，模拟则按分档规则避免同档重复买入，两者不能视为实际订单复现。

场外基金只使用自身导入的历史净值，不拿场内ETF或指数代替。数据不足、日期冲突或共同日期缺失时不生成结果。先看数据覆盖与计算口径，再比较收益、回撤和现金等待成本。

## 备份恢复

“导出”包含完整组合和可导出设置，不含API Key。“导入”先展示产品/交易数量，确认后替换组合；原组合会自动备份。设置里的“恢复本地备份”可恢复迁移前或之前备份，恢复前再次备份当前状态。恢复到旧版数据后会重新出现迁移预览。
